# Environment Setup Instructions

To contribute to or run the `tree-sitter-salesforce` parser locally, you need to set up your development environment. This parser consists of C code (generated by Tree-sitter) and JavaScript configuration, so it requires both Node.js and a C/C++ build toolchain.

## Prerequisites

1. **Node.js**: (Version 18+ recommended). Used for the `tree-sitter-cli` and generating the parser.
2. **C/C++ Compiler**: 
   - **Windows**: Install Visual Studio Build Tools with the "Desktop development with C++" workload.
   - **macOS**: Install Xcode Command Line Tools (`xcode-select --install`).
   - **Linux**: Install `gcc` or `clang`, and `make`.
3. **Python (Optional)**: Used by some developers if testing Python bindings locally.

## Setup Steps

### 1. Clone the Repository
Clone the repository to your local machine:
```bash
git clone https://github.com/your-org/tree-sitter-salesforce.git
cd tree-sitter-salesforce
```

### 2. Install Dependencies
Install the required Node.js packages. This will also trigger `node-gyp` to compile the C bindings for the local environment.
```bash
npm install
```

### 3. Generate the Parser
If you modify `grammar.js`, you must regenerate the C code.
```bash
npx tree-sitter generate
```

### 4. Run Tests
Ensure everything is working correctly by running the corpus tests.
```bash
npx tree-sitter test
```

## Useful Commands
- `npm run build`: Typical alias to regenerate and rebuild.
- `npx tree-sitter parse <file>`: Parse a specific `.cls` or `.trigger` file to see the AST output in your terminal.
- `npx tree-sitter parse --stat <file>`: See performance statistics for parsing a file.
